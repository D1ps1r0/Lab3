# Лабораторна №3 — Абстрактні класи та інтерполяція

Відкрити `LissajousLab3.csproj` у Visual Studio і натиснути F5.

Початкові значення:
h1 = 0,5
h2 = 0,05
функція = sin(x)
діапазон = 0 ... 2π

Для захисту можна показати:
1. h2 >= h1 — програма видає помилку.
2. Звичайні точки — рівновіддалена сітка.
3. Увімкнути «Нерівновіддалені опорні точки».
4. Вимикати/вмикати криві CheckBox.
5. Показати LinearInterpolation.cs і HermiteInterpolation.cs.
6. Показати масив Interpolation[] у MainViewModel.cs.

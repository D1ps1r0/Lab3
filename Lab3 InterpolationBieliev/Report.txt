ЛАБОРАТОРНА РОБОТА №3
АБСТРАКТНІ КЛАСИ ТА ІНТЕРПОЛЯЦІЯ ДАНИХ

Тема: WPF-візуалізація, абстрактний клас, успадкування, поліморфізм, лінійна та кубічна інтерполяція Ерміта.

Мета: зрозуміти відновлення значень між опорними точками, застосувати поліморфізм і показати результат у WPF без залежності алгоритмів від інтерфейсу.

1. ТЕОРЕТИЧНІ ВІДОМОСТІ

Інтерполяція відновлює значення функції між відомими опорними точками. У роботі використовується тестова функція y = sin(x).

Лінійна інтерполяція:
t = (x - xᵢ)/(xᵢ₊₁ - xᵢ)
y = yᵢ + t(yᵢ₊₁ - yᵢ)

Для кубічної інтерполяції Ерміта:
h00 = 2t³ - 3t² + 1
h10 = t³ - 2t² + t
h01 = -2t³ + 3t²
h11 = t³ - t²

y(t) = h00·yᵢ + h10·Δx·mᵢ + h01·yᵢ₊₁ + h11·Δx·mᵢ₊₁

Похідні оцінюються скінченними різницями. Для внутрішніх точок використовується центральна різниця, для крайніх — одностороння.

2. РЕАЛІЗАЦІЯ

Створено абстрактний клас Interpolation з методом Calculate. Від нього успадковано LinearInterpolation та HermiteInterpolation.

Для поліморфізму використано один масив посилань:
Interpolation[] methods =
{
    new LinearInterpolation(),
    new HermiteInterpolation()
};

3. АЛГОРИТМ

1) Вводяться h₁ та h₂.
2) Перевіряється h₁ > 0, h₂ > 0 та h₂ < h₁.
3) Формується A1 з великим кроком h₁.
4) A2 обчислюється з дрібнішим кроком h₂.
5) Для A2 виконуються лінійна та Ермітова інтерполяції.
6) Будуються еталонна, лінійна та Ермітова криві.
7) Обчислюється абсолютна похибка.
8) Будується графік похибки.
9) Окремо перевіряються нерівновіддалені опорні точки.
10) Однакові X заборонені.

4. ДОСЛІДЖЕННЯ

При h₁ = 0,5 та h₂ = 0,05 формується набір опорних точок і густіший набір точок для порівняння методів.

Лінійна інтерполяція дає ламану криву. Ермітова інтерполяція враховує оцінки похідних, тому крива є плавнішою та зазвичай краще наближає sin(x).

У програмі є прапорець для нерівновіддалених опорних точок. Алгоритми працюють не лише для рівномірної сітки, оскільки формули використовують фактичні координати X.

5. ВИСНОВКИ

Під час лабораторної роботи було реалізовано абстрактний клас Interpolation та два поліморфні методи: LinearInterpolation і HermiteInterpolation. Було побудовано WPF-візуалізацію, додано Binding, CheckBox, перевірку h₂ < h₁ та графік абсолютної похибки.

Лінійна інтерполяція є простою, але дає ламану траєкторію. Інтерполяція Ерміта використовує похідні та дозволяє отримати більш плавне відновлення даних. Такий підхід можна використати для побудови плавної траєкторії руху об'єкта в анімації.

6. ПИТАННЯ ДО ЗАХИСТУ

1. Що саме відновлює інтерполяція?
Вона відновлює значення функції між відомими опорними точками.

2. Чому HermiteInterpolation успадковується від Interpolation?
Тому що це один із конкретних способів інтерполяції. Базовий клас задає спільний метод Calculate, а похідний клас реалізує його по-своєму.

3. Звідки беруться похідні у формулі Ерміта?
Якщо вони не задані, їх оцінюють скінченними різницями: для внутрішніх точок центральною різницею, для крайніх — односторонньою.

4. Чим інтерполяція відрізняється від апроксимації?
Інтерполяція повинна проходити через задані опорні точки. Апроксимація лише намагається наблизити набір даних і не обов'язково проходить через кожну точку.

5. Як ця робота переноситься на анімацію траєкторії?
Опорні точки можна задавати як положення об'єкта в різні моменти часу, а інтерполяція обчислює проміжні положення для плавного руху.

7. ВІДПОВІДНІСТЬ ВИМОГАМ

- абстрактний клас Interpolation;
- успадкування LinearInterpolation та HermiteInterpolation;
- поліморфізм через масив Interpolation[];
- WPF Canvas та окремі Polyline;
- CheckBox для видимості кривих;
- поля h₁ та h₂;
- перевірка h₂ < h₁;
- перевірка однакових X;
- рівновіддалені та нерівновіддалені точки;
- графік абсолютної похибки;
- алгоритми знаходяться окремо від View.
